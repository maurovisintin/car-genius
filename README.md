# Car Genius

A guided car-buying assistant. Answer a short, adaptive questionnaire about your budget, lifestyle, and priorities, and get personalized car recommendations generated by Claude.

## Stack

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4 + shadcn/ui
- `@anthropic-ai/sdk` with structured outputs (Zod)
- Claude Opus 4.7

## Getting started

```bash
npm install
cp .env.local.example .env.local
# edit .env.local and add your ANTHROPIC_API_KEY
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## How it works

- `lib/questions.ts` — question graph with branching (`next(answers)`)
- `lib/wizardReducer.ts` — state machine (`ANSWER` / `BACK` / `JUMP_TO` / `SUBMIT` / `RESET`)
- `components/wizard/` — UI (landing, `Wizard`, `QuestionCard`, `Summary`, `Recommendations`)
- `app/api/recommend/route.ts` — POST `{ answers }`, validated with Zod, forwarded to Claude
- `lib/anthropic.ts` — calls `messages.parse` with a Zod schema so the response is guaranteed to be structured JSON

Branches today:

- `fuelType = electric | plug-in hybrid` &rarr; asks about charging access
- `priorities` includes `performance` &rarr; asks for the target performance level
- `priorities` includes `safety` &rarr; asks which safety features are must-haves
- `usage` includes `off-road` or `towing` &rarr; asks about drivetrain (and towing capacity)
- `newOrUsed = used` &rarr; asks max age
